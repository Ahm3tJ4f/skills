# STE Compliance Checklist

Use during Step 4 verification (SKILL.md). Check every item. Each rule must either pass or be flagged with a violation and a suggested rewrite. Do not stop after finding one issue.

---

## 0. Text Type

- [ ] Every sentence classified as procedural or descriptive
- [ ] Procedural and descriptive passages are separated - not mixed in the same paragraph or list

## 1. Words (Rules 1.1–1.14)

- [ ] Every word is either approved in the dictionary, a technical noun (one of 22 categories), or a technical verb (one of 4 categories)
- [ ] Each approved word used only in its specified part of speech
- [ ] Each approved word used only in its single approved meaning
- [ ] Approved verb forms only (no progressive, no present perfect, no complex auxiliary constructions)
- [ ] Past participle used as adjective only, not as a verb form
- [ ] Technical nouns not used as verbs ("apply oil", not "oil" as a verb)
- [ ] Technical verbs not used as nouns
- [ ] No regional, slang, or jargon words as technical nouns
- [ ] Consistent terminology - same object, same name, throughout the document
- [ ] American English spelling (Merriam-Webster); British forms converted
- [ ] Spelling exceptions: quoted text preserved as-is; official directives followed

## 2. Multi-Word Nouns (Rules 2.1–2.2)

- [ ] No noun cluster longer than 3 words without prepositional phrase break
- [ ] Long technical nouns (>3 words) written in full on first use, then shortened or abbreviated with explanation

## 3. Verbs (Rules 3.1–3.7)

- [ ] Only approved verb forms and tenses used (infinitive, imperative, simple present, simple past, simple future, past participle as adjective)
- [ ] Only approved modals used: CAN and MUST. Not approved: may, might, shall, should, would; COULD not used for possibility
- [ ] No -ing forms as verbs (only as technical nouns or modifiers within technical nouns)
- [ ] Active voice in procedures; active preferred in descriptions
- [ ] Passive in descriptions only when agent is genuinely unknown
- [ ] Actions described with verbs, not nouns ("shows", not "gives an indication of")

## 4. Sentences (Rules 4.1–4.5)

- [ ] Each procedural sentence ≤ 20 words
- [ ] Each descriptive sentence ≤ 25 words
- [ ] No contractions ("don't", "isn't", "can't" - write in full)
- [ ] No omitted subjects, verbs, or articles
- [ ] Vertical lists used for complex sequences (formatted per Rule 4.3)
- [ ] Connecting words used appropriately between related sentences
- [ ] Articles used where needed; omitted only for general statements or before alphanumeric identifiers

## 5. Procedural Writing (Rules 5.1–5.5)

- [ ] Maximum 20 words per sentence
- [ ] One instruction per sentence (exception: simultaneous actions or immediately-following results)
- [ ] Instructions in imperative form
- [ ] Conditions before commands, separated by comma
- [ ] Notes contain only information, not instructions

## 6. Descriptive Writing (Rules 6.1–6.6)

- [ ] Maximum 25 words per sentence (6.3)
- [ ] One topic per paragraph; topic sentence at the start (6.5)
- [ ] Maximum 6 sentences per paragraph (6.6)
- [ ] Active voice; passive only when agent is unknown (Rule 3.6 - applies to descriptions too)
- [ ] Simple present tense for general statements and characteristics (Rule 3.2 - applies to descriptions too)
- [ ] No instructions within descriptive text (Section 6 preamble)

## 7. Safety Instructions (Rules 7.1–7.3)

- [ ] Two safety levels only: WARNING (injury/death) and CAUTION (damage to objects). NOTE is not a safety instruction - it is governed by Rule 5.5
- [ ] Each safety sentence starts with a clear command or condition
- [ ] Each safety sentence ≤ 20 words (Rule 5.1)
- [ ] Each safety sentence includes an explanation of the risk (7.3)
- [ ] Legal-controlled warning text flagged for human review (practice, not a numbered rule)

## 8. Punctuation and Word Count (Rules 8.1–8.7)

- [ ] No semicolons (8.1) - split into separate sentences
- [ ] Hyphens used to connect directly related words (8.2)
- [ ] Parentheses used correctly: references, identifiers, work steps, abbreviations, singular/plural, explanations, alternatives (8.3)
- [ ] Vertical lists: text before colon obeys word limit; each item is a new sentence with its own limit (8.4)
- [ ] Parenthetical text counted as one word in the host sentence (8.5)
- [ ] Word-count rules applied: numbers, units, abbreviations, identifiers, quoted text, titles, proper nouns each count as one word (8.6)
- [ ] Hyphenated words counted as one word (8.7)

## 9. Writing Practices (Rules 9.1–9.4 + GR-1–GR-8)

- [ ] Word-for-word replacement attempted first; different sentence construction used only when needed (9.1)
- [ ] Each approved word used in its single approved meaning and part of speech (9.2) - e.g. "wear", "see", "turn", "work", "help", "damage"
- [ ] No phrasal verbs built from approved words (9.3) - e.g. "put out" → "extinguish", "give off" → "release"
- [ ] Consistent terminology and wording - same item same noun, same instruction same wording, throughout (9.4)
- [ ] (GR-1) Conjunction "that" used after "make sure", "show", "recommend"
- [ ] (GR-2) Preposition "with" checked for ambiguity; conditions written first; primary action verb shown
- [ ] (GR-3) Pronouns unambiguous; only approved pronouns used
- [ ] (GR-4) Referent of "this" made clear
- [ ] (GR-5) False friends checked (non-native writers)
- [ ] (GR-6) No Latin abbreviations (e.g., i.e., etc.) - use English words
- [ ] (GR-7) Gender-neutral language; no "he"/"she", no "man"/"woman" unless necessary
- [ ] (GR-8) Possessive form used correctly or avoided

---

## Summary

After checking all items above, produce a summary:

- **All clear** - No violations found. The text is STE-compliant.
- **Violations found** - [N] items failed. Each flagged with the rule number, offending text, and suggested rewrite.
- **Needs human review** - Safety/legal text affected. Changes flagged but not applied.
