Bottom line

Docker keeps each layer in a cache. When one layer changes, Docker builds it and all layers after it again. Copy the dependency files first and the source code last.

Layers and the Cache

Each instruction in a Dockerfile makes a layer. Docker keeps each layer in a cache.

In the next build, Docker uses a layer from the cache if the instruction and its input files did not change. {{fig:layers}} shows the layers of one image.

The Order of Instructions

When one layer changes, Docker builds that layer again. It also builds all layers after it. {{fig:decision}} shows the decision for each instruction.

Two orders of instructions
OrderAfter a change in src/
COPY . . then RUN pnpm installpnpm install runs again.
COPY package.json pnpm-lock.yaml, RUN pnpm install, then COPY . .pnpm install comes from the cache.

{{tab:order}} shows why the second order is faster for each code change.

Caution

Do not copy secrets into an image. If a later instruction deletes the file, the file stays in the earlier layer.
